# קניות ביחד · CartSync 🛒

רשימת קניות אחת ומשותפת למשק בית: כל אחד מוסיף, מסמן "נלקח" בזמן אמת, ורואה מה שאר המשפחה כבר לקחה — גם כששניים נמצאים בו-זמנית בסופר, כל אחד בחלק אחר.

נבנה עם אותם אלמנטים טכניים כמו [tsaad-katan](https://github.com/smkrot3-sudo/tsaad-katan): אתר סטטי שנבנה מחלקים (`web/parts/`), Supabase לענן (אימייל+סיסמה, סנכרון בזמן אמת), ובהמשך גם APK לאנדרואיד + PWA לאייפון.

## מצב נוכחי (שלב 1)

- ✅ הרשמה/התחברות עם מייל וסיסמה (Supabase Auth)
- ✅ יצירת "משק בית", הזמנת חברים בקוד, מעבר בין כמה משקי בית
- ✅ רשימת קניות משותפת עם סנכרון בזמן אמת (Supabase Realtime)
- ✅ מיון אוטומטי לקטגוריות + אימוג'י לכל מוצר (מילון מקומי, בלי AI עדיין)
- ✅ הרשאות ברמת הדאטהבייס: בעלים/עריכה מלאה/בקשת מוצרים (דורש אישור)/צפייה בלבד — אבל כרגע כולם מצטרפים כ"עריכה מלאה"; ממשק לניהול הרשאות לחברים עדיין לא קיים
- ✅ דו-לשוני: עברית (RTL) ואנגלית (LTR), מתחלף בלחיצה
- 🚧 עדיין לא קיים: קטגוריזציה עם AI אמיתי, ממשק לשינוי תפקיד חבר, מחיקת חשבון, APK לאנדרואיד, PWA icons אמיתיים (יש placeholder), עמוד פרטיות

## ארכיטקטורה

- `web/parts/` — המקור: `base.css`+`extra.css` (עיצוב), `body.html` (שלד ה-DOM), `i18n.js` (עברית/אנגלית), `app.js` (רינדור + מיון קטגוריות מקומי, בלי רשת), `cloud.js` (Supabase: אימות, משקי בית, רשימה, realtime)
- `tools/build_web.py` — מאחד את `web/parts/` ל-`docs/index.html` (האתר החי) ול-`web/preview.html` (תצוגה מקדימה בלי ענן, לעיצוב מהיר)
- `supabase/` — יהיו כאן migrations/edge functions כשנצטרך; הסכמה הנוכחית הוחלה ישירות על הפרויקט (לא נשמרה כקובץ מקומי עדיין — ראו "מסד הנתונים" למטה)

## מסד הנתונים

**משותף עם פרויקט tsaad-katan ב-Supabase** (`pzrzwilkloksfxsvcwji`), כדי לא לפגוע ב-2 הפרויקטים החינמיים הקיימים (tsaad-katan + budget). הטבלאות החדשות (`households`, `household_members`, `household_invites`, `shopping_lists`, `list_items`) נפרדות לגמרי מהטבלאות של צעד קטן, עם RLS משלהן. אם בהמשך ירצו לנתק — אפשר לייצא ולהעביר לפרויקט Supabase נפרד.

## הרצה מקומית

```bash
python tools/build_web.py   # בונה את docs/index.html מהחלקים
npx serve docs -l 5555      # שרת מקומי
```

פותחים http://localhost:5555
